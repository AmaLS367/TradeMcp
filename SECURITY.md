# 🔒 Security Policy

![Security](https://img.shields.io/badge/security-critical-red)

---

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability in Trade MCP, please report it **privately**:

[🔐 Report on GitHub Security Advisories](https://github.com/AmaLS367/TradeMcp/security/advisories/new)

> ⚠️ **Do not** report security issues publicly in the issue tracker.

---

## 📝 What to Include

- 📌 Description of the vulnerability
- 🔄 Steps to reproduce
- 💥 Potential impact
- 🔧 Suggested fix (if applicable)
